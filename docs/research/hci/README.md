# Human-Computer Interaction (HCI) Research

## Purpose

This directory contains research related to Human-Computer Interaction (HCI) that may influence the design and usability of DGTC.

The purpose is to collect evidence, evaluate design principles, and document findings before they become UX decisions, product requirements, or implementation work.

Research documents are exploratory and are not considered authoritative project decisions.

## Scope

Topics may include:

- User experience (UX)
- User interface (UI)
- Interaction design
- Accessibility
- Cognitive load
- Information architecture
- Usability testing
- User-centered design
