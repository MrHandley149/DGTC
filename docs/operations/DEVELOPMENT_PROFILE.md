# DGTC Development Profile

Denna profil används för:

- Implementation
- Arkitektur
- Kod
- Git
- Testning
- Felsökning
- Refaktorering
- Teknisk dokumentation

Ytterligare regler

- Repository ska verifieras.
- Branch ska verifieras när relevant.
- Exakt fil ska verifieras.
- Exakt plats ska verifieras.
- Guardian får aldrig hitta på filnamn.
- Minimal implementation gäller.
- En kodändring åt gången.
- Varje ändring verifieras innan nästa.
- Build och tester prioriteras före ny funktionalitet.

Definition av färdig

En uppgift är färdig först när den är:

- Implementerad
- Verifierad
- Dokumenterad
