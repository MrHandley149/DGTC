# Syfte

Detta dokument är projektets officiella dokumentregister.

Syftet är att ge en samlad översikt över:

* vilka dokument som finns
* vilken status de har
* vilka dokument som är frysta
* vilka dokument som är aktiva
* vilka dokument som är planerade
* vilka dokument som har förbättringsförslag i Change Queue

Detta dokument beskriver **inte** innehållet i dokumenten.

Projektstatus hanteras i **MASTER_INDEX.md**.

---

# Dokumentstatus

Följande status används i projektet.

| Status     | Betydelse                               |
| ---------- | --------------------------------------- |
| Planned    | Dokumentet är planerat men inte skapat. |
| Draft      | Första arbetsversion.                   |
| Review     | Under granskning.                       |
| Approved   | Godkänt och aktivt.                     |
| Frozen     | Fryst. Får inte ändras.                 |
| Deprecated | Ersatt av annat dokument.               |
| Archived   | Arkiverat. Används inte längre.         |

# Dokumentprinciper

1. GitHub (main) är projektets officiella sanningskälla.
2. MASTER_INDEX beskriver projektets status.
3. DOCUMENT_REGISTER beskriver projektets dokument.
4. Frysta dokument får inte ändras.
5. Alla förbättringsförslag läggs i Change Queue.
6. Ett dokument byter endast status efter ett uttryckligt projektbeslut.
7. Dokument tas aldrig bort. De markeras i stället som **Deprecated** eller **Archived**.
