# DGTC Messaging Framework

**Status:** v0.1 Draft

**Dokumenttyp:** Core Document

---

# Syfte

Messaging Framework översätter DGTC:s identitet till konsekventa budskap.

Dokumentet säkerställer att all extern kommunikation uttrycker samma kärnbudskap, oavsett kanal eller målgrupp.

Messaging Framework bygger på Foundation, Foundation Analysis, Business Guardrails och Brand Platform.
