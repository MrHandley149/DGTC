# DGTC Messaging Framework

**Version:** 1.0

**Status:** Draft

**Document Type:** Core Business Document

---

# Purpose

The Messaging Framework translates the DGTC brand into consistent communication.

Its purpose is to ensure that every external message expresses the same strategic identity regardless of audience, platform, or communication channel.

This framework transforms philosophy into language.

It defines **what we say**, **how we say it**, and **why it matters**.

The Messaging Framework is built upon:

- Foundation
- Foundation Analysis
- Business Guardrails
- Brand Platform

It does not introduce new product strategy.

# Core Message

Every piece of communication should reinforce the same central idea.

> **DGTC helps people grow by enabling better understanding, better decisions, and meaningful practice.**

Disc golf is the first application.

Human development is the larger purpose.

Whenever communication becomes too complex, this message should remain recognizable.

---

# Message Pillars

## 1. Develop People

DGTC exists to help people improve.

Improvement is measured by better understanding, better decisions, and long-term development—not simply better scores.

---

## 2. Build Understanding

Data has value only when it creates understanding.

Artificial intelligence exists to explain rather than overwhelm.

Users should leave every interaction knowing more than before.

---

## 3. Earn Trust

Trust is built through transparency.

DGTC communicates honestly, openly, and without exaggeration.

Long-term credibility is considered more valuable than short-term marketing success.
# Translation Framework

The Translation Framework ensures that every external message can be traced from philosophy to communication.

| Foundation Principle | Brand Platform Translation | Messaging Expression |
|----------------------|----------------------------|----------------------|
| Help people grow | Human development comes first | "Improve through better understanding." |
| Better decisions | Decision support over statistics | "Make smarter decisions—not just better scores." |
| Positive First | Build confidence before challenge | "Progress begins with confidence." |
| AI as a coach | AI supports, never replaces | "AI that explains, not controls." |
| Transparency | Honest and open communication | "No hidden agendas. No lock-in." |
| User ownership | Respect user autonomy | "Your development belongs to you." |

Every communication should remain consistent across all three layers.

# Proof Points

Every major message should be supported by observable evidence.

The preferred structure is:

```text
Message
      │
      ▼
Product Capability
      │
      ▼
User Benefit
      │
      ▼
Real Outcome
```

Marketing claims should always be supported by demonstrable functionality.

Features alone are not proof.

Outcomes create credibility.

# Communication Hierarchy

Not every message carries the same strategic importance.

The order in which information is communicated should reinforce the DGTC philosophy.

## First

Communicate:

- Human development
- Better understanding
- Better decisions
- Positive learning
- Long-term value

These messages establish the identity of the product.

---

## Next

Communicate:

- Product capabilities
- Artificial intelligence
- Analytics
- Features
- Platform functionality

Technology should explain the philosophy—not replace it.

---

## Never First

Avoid leading communication with:

- Feature lists
- Technical specifications
- Artificial intelligence
- Statistics
- Comparisons with competitors
- Marketing claims without evidence

The product should always be introduced through its purpose before its functionality.

---

# Message Checklist

Before publishing significant communication, verify the following.

- Does this align with the Foundation?
- Does this align with the Brand Platform?
- Is the message easy to understand?
- Does it help the user?
- Does it build trust?
- Can it be traced back through the Translation Framework?

If any answer is **No**, the communication should be revised before publication.

---

# Governance

The Messaging Framework governs all external communication, including:

- Website content
- App Store descriptions
- Google Play listings
- Social media
- Advertising
- Press releases
- Investor presentations
- Sponsorship material
- Educational content

Every communication channel should reinforce the same identity while adapting only its level of detail.
