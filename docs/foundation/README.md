# DGTC Foundation

## Purpose

The Foundation defines **why DGTC exists, how it behaves and how it teaches.**

Everything in this folder is considered the long-term foundation of the product.

The Foundation is technology independent.

Implementation may change.

The philosophy should not.

---

# Status

**Status:** Frozen

Foundation documents may not be modified during normal product development.

Ideas for improvements are added to the **Change Queue** and evaluated separately.

# Rules

When working from the Foundation:

- Read only documents in this folder.
- Treat these documents as the project's authoritative Foundation.
- Never modify Foundation documents unless explicitly instructed.
- Never present interpretations as project decisions.
- If information requires interpretation, clearly label it as a recommendation.
- If documents appear to conflict, report the conflict instead of resolving it.

---

# Intended Usage

The Foundation may be used to:

- understand DGTC's philosophy
- understand DGTC's learning model
- understand DGTC's performance model
- derive product behavior
- derive business strategy
- derive marketing messages
- derive onboarding material
- derive brand messaging

The Foundation must **not** be rewritten when creating business or product documents.

---

# AI Instructions

When an AI assistant is asked to analyze DGTC using only the Foundation, it should:

1. Read every document listed above.
2. Use only information from those documents.
3. Clearly distinguish between:
   - Direct quotes
   - Summaries
   - Recommendations
4. Never introduce information from outside the Foundation.
5. If information is missing, state that it is missing rather than making assumptions.
