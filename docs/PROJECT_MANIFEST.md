## Operating Invariants

- GitHub is the Single Source of Truth.
- Execute Before Explain.
- Known Structure Before Search.
- Automatic Documentation Synchronization.
- The Product Owner is the final decision-maker for product and governance.
- Git Operations executes and verifies repository work but makes no subject-matter decision.
