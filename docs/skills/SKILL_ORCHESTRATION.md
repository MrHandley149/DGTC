## Purpose

This document defines how registered competence roles are selected, bounded, and cross-reviewed.

## Orchestration Rules

1. Select only roles registered in the [Skill Library Index](SKILL_LIBRARY_INDEX.md).
2. Activate roles because their documented competence is relevant, not because a repository operation is required.
3. Keep recommendations separate from Product Owner decisions.
4. Require cross-review by affected competence roles for material multidisciplinary content.
5. Use a Verklighetskontroll or equivalent evidence function when material uncertainty, external evidence, or significant risk is present.
6. Route authorized repository execution and control to [Git Operations](../operations/GIT_OPERATIONS.md), which is not a competence role and has no subject-matter mandate.

No role may approve its own material output on behalf of the Product Owner.
