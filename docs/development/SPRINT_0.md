# Sprint 0

**Status:** Planning

---

# Sprint Goal

Etablera utvecklingsplattformen så att Sprint 1 kan fokusera helt på produktutveckling.

Sprint 0 ska leverera en stabil utvecklingsmiljö, ett fungerande arbetsflöde och ett projekt som kan byggas, köras och vidareutvecklas utan hinder.

---

# Definition of Done

Sprint 0 är färdig när:

- Projektet kan byggas från GitHub.
- Alla utvecklingsverktyg är installerade och verifierade.
- Repository-strukturen är fastställd.
- Utvecklingsarbetsflödet är dokumenterat.
- Första applikationen kan startas.
- CI (om vi väljer att ha det från början) fungerar.
- Sprint 1 kan påbörjas utan ytterligare infrastrukturarbete.

---

# Scope

Sprint 0 omfattar endast utvecklingsplattformen.

Produktfunktioner, användargränssnitt och affärslogik ingår inte.
