# Disc Golf Training Companion (DGTC)

DGTC is a disc golf training platform focused on structured practice, player development, and meaningful feedback.

This repository contains the product foundation, requirements, architecture, governance, and development documentation for DGTC.

## Start here

Open the [documentation index](docs/MASTER_INDEX.md) to navigate the project documentation.

## Repository purpose

The repository is the shared source for DGTC product development.

The documentation covers:

- product vision and principles,
- product requirements,
- functional requirements,
- architecture and technical models,
- governance and recorded decisions,
- development workflows and supporting guides.

## Current status

DGTC is currently in its foundation and MVP preparation phase.

Current work, project status, and planned activities are maintained in the appropriate project documents referenced from the documentation index.

## Working with the repository

Before changing product behavior, architecture, or documentation:

1. Locate the relevant authoritative document through the documentation index.
2. Review existing decisions and requirements.
3. Follow the applicable development workflow.
4. Update affected documentation together with the change.
